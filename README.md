# Cards & Dungeons

Unity 6（6000.5.5f1）で開発されたRoguelike型ダンジョン探索ゲームです。  
プレイヤーは戦闘中にカードを組み合わせて戦略的に敵を倒し、ダンジョンを攻略します。

---

## 🎮 ゲーム概要

**ジャンル:** Roguelike / ダンジョン探索 / デッキビルディング  
**言語:** C# 81.7% / ShaderLab 15.2% / HLSL 3.1%

### 主な特徴

- **デッキビルディングシステム:** 敵を倒すことでカードを獲得し、自分のデッキを強化
- **ダイナミック戦闘:** バフカードとダメージカードを組み合わせた戦略的なターンベース戦闘
- **ランダムダンジョン生成:** 毎回異なるダンジョンを探索（プロシージャル生成）
- **ミニマップシステム:** Texture2Dベースのリアルタイムミニマップで探索状況を可視化

## 🎯 ゲームシステム

### 1. **カードシステム**

#### カードタイプ
- **バフカード (Buff):** パッシブな能力強化
  - 攻撃力UP
  - 最大HP UP
  - 攻撃範囲UP
  - クリティカル確率UP
  - 倍率UP

- **消費カード (Use):** アクティブに使用する効果
  - **ダメージカード:** 敵に指定範囲でダメージを与える
  - **回復カード:** HPを回復

#### ドロップシステム

```csharp
// 敵撃破時のカード報酬抽選
- 1～3回目の敵撃破：確定でバフカード獲得
- 4回目以降：50%の確率で消費カード出現
```

### 2. **ダンジョンシステム**

#### ミニマップ機能
- **視界システム:** プレイヤーの視野範囲をリアルタイムで計算
- **探索記録:** 発見済みのタイル情報を記録・表示
- **階段アイコン:** ダンジョン内の下り階段を表示

### 3. **ゲーム進行**

```
タイトル画面
  ↓
ゲーム開始
  ↓
ダンジョン探索 → 敵と遭遇 → 戦闘 → カード報酬
  ↓ (ダンジョン攻略)
ゲームクリア → スタッフロール → タイトル画面に戻る
```

## 🎮 ゲームプレイ

### 基本操作

| 操作 | 説明 |
|------|------|
| **矢印キー / WASD** | プレイヤー移動 |
| **クリック / 選択** | カード使用・UI操作 |
| **R** | カード抽選回数リセット（デバッグ用） |

### 戦闘の流れ

1. **敵との遭遇:** ダンジョン内で敵が出現
2. **カード選択:** 手持ちのカードから使用するカードを選択
3. **効果発動:** 選択したカードの効果が敵に適用
4. **敵の攻撃:** 敵から反撃を受ける
5. **繰り返し:** 敵が倒れるまで続行
